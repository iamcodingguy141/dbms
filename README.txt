DBMS VIVA — SETUP (NO FIREBASE)
1. Create a private Google Sheet. Copy its ID from the URL between /d/ and /edit.
2. At script.google.com create a new standalone project named Viva Registration. Paste Registration_Code.gs into Code.gs. Replace SHEET_ID. Deploy > New deployment > Web app. Execute as Me; access Anyone. Authorize and copy the /exec URL.
3. Create a DIFFERENT standalone Apps Script project named Viva Admin. Paste Private_Admin_Code.gs, replace SHEET_ID with the same ID. In the editor select setupAdmin_ and Run once, authorize. If the editor does not list private functions, temporarily rename it to setupAdmin, run it, then rename back to setupAdmin_ before deploying. Remove the setupAdmin_ function after it has run, to remove the password literal. Deploy > New deployment > Web app. Execute as Me; access Only myself. Copy /exec URL.
4. Open index.html or index-code.txt and replace the two URL placeholders REGISTRATION_URL and ADMIN_URL with the corresponding deployment URLs. Upload ONLY index.html to GitHub Pages (or paste the edited TXT into index.html). Never upload the backend or credential files to GitHub.
5. Open the deployed site, enter a test student name, then use DO NOT TOUCH > Admin login. Sign in with the Google account that deployed the private project if prompted, then use the credentials in PRIVATE_CREDENTIALS.txt. Refresh names in the dashboard. Test in another browser/device.
6. To change the password, edit ADMIN_PASSWORD under Apps Script Project Settings > Script properties in the PRIVATE project. Do not put it in frontend code.
Notes: The public registration endpoint accepts self-reported names and can be spammed; it does not return names. A random registration ID deduplicates refreshes, not different devices. Only names and IDs are transmitted. Existing progress remains local. Google Workspace policies may prevent public deployment. No live deployment or browser test has been performed. If deployment URLs are absent, the button opens a dialog explaining setup instead of pretending login is available. A failed registration can be retried by refreshing. The ZIP contains private credentials; do not distribute it.
